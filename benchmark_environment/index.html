1. Collect the 1,000-trajectory training dataset

The Particle NeRD training set has 1,000 native implicit-MPM trajectories of 6 s, recorded at 200 Hz in the same sand bed and material. It has two parts: 600 trajectories with elementary objects (box, sphere and cylinder, each with 120 prescribed-motion and 80 free-body trajectories) and 400 particle free-fall trajectories (sand blocks and columns released onto flat ground, with no rigid object). The robot cases on this page (Franka, Go2, G1) are not part of the set. The split is fixed by trajectory ID: 800 train, 100 validation and 100 test.

One command records the whole set: the object trajectories, then the free-fall trajectories, then a check of the complete set. From the repository root, with the output directory and the number of GPUs to use:

bash examples/particle_nerd_benchmark/learning/collect_dataset.sh /path/to/dataset 4     # about 135 GB

On OSMO a single command submits the same collection and writes directly to a private bucket:

bash examples/particle_nerd_benchmark/learning/osmo/collect_all.sh swift://PRIVATE_BUCKET/particle-nerd-object-benchmark --pool POOL

The set covers a flat sand bed only. Prescribed motions are horizontal push, vertical intrusion, circling and holding; free bodies are dropped, slid, thrown or tumbled. The terrain variants (ascend, descend, wave), the sphere rolling and the shallow projectile cases in the gallery below are separate reference cases and are not part of this set. The collected set is private and is not hosted on this site. Training expects the six object folders (box-prescribed, box-dynamic, sphere-prescribed, sphere-dynamic, cylinder-prescribed, cylinder-dynamic) and the freefall folder under one data root.

2. Simulation conditions and recording

Each clip is a fresh native implicit-MPM run. Particles and body states are saved at 200 Hz; video frames are captured from those same states at 50 fps. The first second prepares the object scenes before intrusion. Robot controllers run from reset.

The sand uses density 1,600 kg/m³, Young’s modulus 10¹⁵ Pa, Poisson’s ratio 0.3, material friction 0.48, and yield pressure 10¹⁵ Pa. The MPM grid spacing is 0.04 m. Initial particle positions use a 0.032 m lattice with uniform jitter of up to 6.4 mm per coordinate (seed 42), bounded by the initial sand surface and rigid tray. Particle count and mass are unchanged. Franka’s walls end 4 cm above its initial sand surface; other tray walls end at z=0.20 m. These are simulation parameters, not a calibration to a measured sand specimen.

Validation checks particle containment, finite recorded states and forces, actual material contact, and video timestamps. Robot cases also check upright posture and forward motion. These reference rollouts do not measure Particle NeRD prediction accuracy or GPU scalability.
